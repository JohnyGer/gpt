# Промпт для продуктивного изучения предмета

**Как использовать:** скопируй весь блок, напиши свои параметры параметры и вставь в любой LLM (ChatGPT, Claude, Grok и т.д.)

## Шаблон промпта

```
[SUBJECT]=Тема или навык для изучения
[CURRENT_LEVEL]=Начальный уровень знаний (начальный/средний/продвинутый)  
[TIME_AVAILABLE]=Сколько часов в неделю готовы уделять обучению  
[LEARNING_STYLE]=Предпочтительный метод обучения (визуальный/слуховой/практический/чтение)  
[GOAL]=Конкретная цель обучения или целевой уровень навыка   

Шаг 1: Оценка знаний  
1. Разбить [SUBJECT] на основные компоненты  
2. Оценить уровни сложности каждого компонента  
3. Составить карту предпосылок и зависимостей  
4. Выявить фундаментальные концепции  
Вывод: детальное дерево навыков и иерархия обучения  

~ Шаг 2: Проектирование пути обучения  
1. Создать этапы прогресса на основе [CURRENT_LEVEL]  
2. Структурировать темы в оптимальной последовательности обучения  
3. Оценить временные затраты на каждую тему  
4. Согласовать с ограничениями [TIME_AVAILABLE]  
Вывод: структурированная дорожная карта обучения с временными рамками  

~ Шаг 3: Подбор ресурсов  
1. Определить учебные материалы, соответствующие [LEARNING_STYLE]:  
- Видеокурсы  
- Книги/статьи  
- Интерактивные упражнения  
- Практические проекты  
2. Ранжировать ресурсы по эффективности  
3. Создать плейлист ресурсов  
Вывод: полный список ресурсов с приоритетным порядком  

~ Шаг 4: Рамки практики  
1. Разработать упражнения для каждой темы  
2. Создать сценарии реального применения  
3. Разработать контрольные точки прогресса  
4. Структурировать интервалы повторения  
Вывод: план практики с расписанием повторения с интервалами  

~ Шаг 5: Система отслеживания прогресса  
1. Определить измеримые индикаторы прогресса  
2. Создать критерии оценки  
3. Разработать петли обратной связи  
4. Установить метрики завершения этапов  
Вывод: шаблон отслеживания прогресса и ориентиры  

~ Шаг 6: Генерация расписания занятий  
1. Разбить обучение на ежедневные/еженедельные задачи  
2. Включить периоды отдыха и повторения  
3. Добавить контрольные оценки  
4. Сбалансировать теорию и практику  
Вывод: детальное расписание занятий, согласованное с [TIME_AVAILABLE]  

Отвечай на русском языке.
```
